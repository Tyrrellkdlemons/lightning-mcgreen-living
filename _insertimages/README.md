# _insertimages — drop background art here

Drop any `.jpg` / `.jpeg` / `.png` / `.webp` files in this folder. They will:

1. Be copied to `public/backgrounds/` at build time by `scripts/sync-insert-images.mjs`.
2. Be listed in `public/backgrounds/manifest.json`.
3. Rotate behind the entire app every **30 seconds** via the
   `<RotatingBackground>` component (mounted in `src/app/layout.tsx`).

No filename convention required — anything that's an image gets picked up.
File order is the alphabetical order of the source filenames, so prefix with
numbers if you want a specific cycle order:

```
_insertimages/
  01-la-skyline-sunset.jpg
  02-la-night-lightning.jpg
  03-la-day-palms.jpg
  04-la-dusk.jpg
```

To trigger a sync without a full build:

```powershell
npm run sync-images
```

To skip these files on a particular deploy, just empty the folder. The
component falls back gracefully (renders nothing) when no images are present.

## Reduce-motion behavior

If the user has `prefers-reduced-motion: reduce` set or has flipped the
header's "Motion" toggle off, the rotation pauses on the first image with a
1.0× scale (no Ken Burns). All other animation rules in
`docs/UI_THEME_GUIDE.md §5` still apply.

## Brand check

Anything you drop here must follow the brand do-not list in
`docs/UI_THEME_GUIDE.md §11`. Don't drop:
- Disney/Pixar Cars characters
- NASCAR sponsor boards
- Real apartment-operator logos you don't own / don't have rights to
- Real dealer logos
- Photos with embedded watermarks from listing portals (Zillow / Apartments.com / etc.)

LA-skyline / urban / racing-track / gingerbread art generated by you or by an
AI you have rights to use is fine.
