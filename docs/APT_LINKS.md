## Where these listings show up in the app

- **`/apartments/apply-engine`** — workbook-aware list, with multi-source links
  (direct listing, official property search, deep apply, Zillow / Rent / Realtor),
  OpenStreetMap link, screening-vendor pre-flight, and prep packet.
- **`/rentals`** — collapsible "Workbook Source Links" panel (searchable, city-filterable,
  show-more so the page stays clean on mobile).
- **Global search** — workbook entries indexed under a `Workbook` result type.

## Notes for ranks where the markdown URL is a *category page* (not a property page)

Many of the URLs above are city/category pages on apartments.com or rentcafe.com
(e.g. `/corona-ca/washer-dryer/`). That's intentional — they're the safe primary
discovery URL the original ranking research used.

To get to the **actual leasing page** for any property, use the engine's
"Direct listing deep link" (DuckDuckGo `!ducky` query) or the OpenStreetMap link
for a satellite/street fix. Both are produced from the JSON in
`scripts/import-ranked-workbook.py`.

If you find a verified direct property URL for any rank, drop it into the JSON's
`direct_links.direct_listing_url` for that listing and the engine + search will
pick it up automatically.
